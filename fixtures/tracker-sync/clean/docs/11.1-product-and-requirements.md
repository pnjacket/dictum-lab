# Product & Requirements

## Contracts

- **`CAP-NOTES`** — a user can create and list notes.
- **`API-LIST-NOTES`** — `GET /notes` — returns all notes (`CAP-NOTES`).

## Acceptance criteria

- **`AC-LIST`** — a created note appears in the list (`CAP-NOTES`, `API-LIST-NOTES`).
