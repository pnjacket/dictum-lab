# Interfaces & Contracts

## Contracts

- **`API-LIST-NOTES`** — `GET /notes` — returns all notes (realizes `CAP-NOTES`).
- **`API-CREATE-NOTE`** — `POST /notes` — creates a note.
- **`ENTITY-NOTE`** — fields: `id`, `title`, `body`.
- **`COMPONENT-EXPORTER`** — exports all notes to a file.
