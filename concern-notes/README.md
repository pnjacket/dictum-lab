# Concern notes — worked examples & design rationale (non-normative)

One file per concern (`11.1`–`11.15`), holding material **migrated out of the
Dictum standard's concern specs** in the 2026-07 compaction audit: the
illustrative **worked examples** and the **design-decision rationale / trial
evidence** that stood behind each bar.

**These files define nothing.** The standard's `concerns/11.x-*.md` remain the
sole statement of the rules and stand on their own — a reader can follow every
bar without anything here. This directory is *deeper insight*: why a bar reads
as it does, and the trial shapes that surfaced it.

Conventions, per this repo's charter:

- **Describe by shape, never by name** — the worked examples use invented
  archetypes ("a planning SaaS", "a real-time messaging service", "a
  client-only browser game"); no real product, repo, or company appears.
- **Non-normative** — where a note and the standard's text disagree, the text
  wins.
- Stable filenames (`11.x-<slug>.md`) so the standard's release-time pin table
  (a later step) can cite them as fixed anchors.
